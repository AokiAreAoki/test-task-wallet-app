# Wallet App

A mobile-first wallet application built with React, TypeScript, Vite, and TailwindCSS.

## Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

## Getting Started

Follow these steps to run the application locally:

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Start the development server**
   ```bash
   npm run dev
   ```

3. **Open the app**
   Open your browser and navigate to the URL shown in your terminal (typically `http://localhost:5173`).

## Available Scripts

- `npm run dev`: Starts the development server.
- `npm run build`: Builds the app for production.
- `npm run preview`: Locally preview the production build.
- `npm run lint`: Runs ESLint to catch errors in the source code.
